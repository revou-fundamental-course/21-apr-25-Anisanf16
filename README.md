🌡️ Website Konversi Suhu - Katcuis
Website Katcuis adalah aplikasi web sederhana yang memungkinkan pengguna untuk mengonversi suhu dari satu satuan ke satuan lainnya secara cepat dan mudah. Website ini dirancang dengan tampilan yang menarik dan responsif, serta dapat diakses melalui berbagai perangkat tanpa perlu menginstal aplikasi tambahan.

✨ Fitur
Konversi suhu dari Celsius ke Fahrenheit, dan sebaliknya

Tampilan antarmuka yang ramah pengguna

Penjelasan cara penggunaan dan rumus konversi

Responsif untuk desktop dan perangkat mobile

Desain dengan elemen visual yang imut dan menarik 🎀

💻 Teknologi yang Digunakan
HTML5 - Struktur halaman

CSS3 - Styling dan desain responsif

JavaScript - Logika konversi suhu dan interaksi pengguna

📚 Cara Menggunakan
Masukkan nilai suhu pada kolom input.

Pilih satuan asal suhu (Celsius atau Fahrenheit).

Pilih satuan tujuan.

Klik tombol Konversi untuk melihat hasilnya.

Klik tombol Riset untuk mengatur ulang form.

🎯 Tujuan Pembuatan
Website ini dibuat sebagai latihan dan proyek pembelajaran dalam memahami dasar-dasar pengembangan web (HTML, CSS, dan JavaScript). Cocok digunakan oleh pelajar, mahasiswa, maupun siapa saja yang membutuhkan konversi suhu secara cepat dan praktis.
